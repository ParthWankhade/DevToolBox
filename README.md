# DevToolBox
DevToolbox is a web-based developer productivity toolkit built with React, Vite, JavaScript, and CSS. It brings commonly used development utilities together in a single interface, helping developers perform routine tasks without switching between multiple tools.

## Features
- **JSON Studio:** Format, validate, and compare JSON data.
- **Encoding Toolkit:** Encode and decode Base64 and URL data.
- **Password & UUID Generators:** Generate passwords and unique identifiers.
- **Text & Regex Tools:** Analyze text and test regular expressions.
- **Timestamp Converter:** Convert between timestamps and readable dates.
- **API Request Tester:** Send HTTP requests and inspect responses.
- **Code Snippet Library:** Create, edit, manage, and copy reusable code snippets.
- **Local Persistence:** Retain supported saved data and preferences in the browser.

## Tech Stack
- React
- Vite
- JavaScript
- CSS
- Browser APIs and localStorage

## Getting Started
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev`.
4. Open the local URL shown in your terminal.

To create a production build, run `npm run build`.
## Project Goal
The goal of DevToolbox is to make frequently used developer utilities accessible through one convenient, maintainable web application.
